HX Documentation

Welcome to HX, a lightweight, flexible HTTP framework for Go that simplifies request handling and data extraction.

Features
--------

* 🚀 **Lightweight and fast** - Minimal overhead with maximum performance
* 💪 **Type-safe request data extraction** - Compile-time safety for request handling
* 🔄 **Automatic request binding** - Seamless data binding from various sources
* 🛠 **Extensible design** - Easy to extend and customize

Requirements
------------

* Go 1.27 or higher
